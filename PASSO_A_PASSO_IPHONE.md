# Guia atualizado de instalação iPhone

O guia da v0.2 foi substituído por **INSTALACAO_V05_IPHONE.md**.

**Use DeepSeek via OpenRouter + Groq**, sem Gemini. Não cole tokens em repositórios, arquivos ou mensagens.

Links:
- OpenRouter (API key): https://openrouter.ai/settings/keys
- Modelo gratuito: https://openrouter.ai/deepseek/deepseek-v4-flash-0731:free
- GitHub Satanabot: https://github.com/xxg101213-max/Satanabot
- Railway: https://railway.com/dashboard

Configuração adicional no Railway:

```
OPENROUTER_API_KEY=SUA_CHAVE_PRIVADA
OPENROUTER_MODEL=deepseek/deepseek-v4-flash-0731:free
AI_MODE=auto
```

Mantenha as variáveis `TELEGRAM_BOT_TOKEN`, `ALLOWED_TELEGRAM_IDS`, `GROQ_API_KEY`, `GROQ_MODEL` e `DATA_DIR` existentes. Leia `INSTALACAO_V05_IPHONE.md` para o passo a passo completo.
